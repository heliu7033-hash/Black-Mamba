# 老黑剪辑台演示

产品名是 **老黑剪辑台**。默认包装是黑曼巴炭黑琥珀：背景 `#080808`，强调色 `#E18C21`，文字 `#FCFCFC`。口播内容和 Remotion 画面保持不动，切换的只有包装。

系列灵感来自抖音创作者老萨的光速剪辑工作台。那是外部来源的署名，不是本仓库的产品名。

## 怎么打开

需要 Node.js 24，并在仓库根目录执行：

```bash
npm install
cp .env.example .env.local
npm run dev
```

浏览器打开（必须是本机 `localhost` 安全上下文）：

```text
http://localhost:5199/#/laohei
```

`#/老黑剪辑台` 同样会打开，并把界面语言切到中文。首次访问会创建工程「老黑剪辑台演示」（时间线名「老黑剪辑台」）。之后从工程列表点开同名工程即可。再访问这个地址不会覆盖你已经改过的包装偏好；只有本机还没有这份偏好时才会写入默认值。

演示不读取用户成片。画面是 Remotion 里的炭黑纯色层加上标题「同一口播 / 内容锁定」。字幕是夹具里的剪后口播，用来驱动章节和语义配卡。三条轨道上已有占位片段：床乐、图解提前、补充画面。

## 五块台面

1. **顶栏**：包装风格（默认黑曼巴炭黑琥珀，另有影棚琥珀、冷科技、清爽白）、中文 / English、小卡 S / 中卡 M / 全卡 F、内容锁定。
2. **检查器**：卡型与顶栏同步，九宫格决定卡片锚点和裁切焦点。
3. **语义配卡**：没有 OpenAI 兼容 API Key 时显示空态，并提供「打开 OpenAI 设置」。密钥只留在本机设置。配好密钥后，可按当前字幕推荐 S/M/F 并采用。
4. **章节**：按剪后字幕的停顿分章。预览上方有章节条，检查器里有章节列表，点击会跳到该章。
5. **时间线轨道**：智能音乐、动效、B-roll。拖入素材会自动落到空档；「智能填充」目前只放下占位片段，没有接模型。

中英切换只换字幕和界面文字，不改声音和时间。本演示没有人声音轨。

## 缺口

- 语义配卡在没有密钥时停在空态。仓库不存放 API Key。
- 智能音乐、动效、B-roll 的「智能填充」只自动落一个占位片段，没有接配乐、提前 0.75 秒图解或 B-roll 模型。
- 演示画面是纯色舞台和标题，不是口播实拍；没有用户媒体，也没有人声。
- 代码与路由标识仍用 `laosa`（例如 `src/laosa/`、`/api/laosa/semantic-card`、占位标签 `laosa:music`）。它们不是界面上的产品名。
