# 老萨包装台演示

口播和 Remotion 画面锁住。包装风格、中文/English、小卡 S / 中卡 M / 全卡 F 只换包装。默认风格是黑曼巴炭黑琥珀：背景 `#080808`，强调 `#E18C21`，文字 `#FCFCFC`。

## 打开

```bash
npm install
npm run dev
```

浏览器打开 [http://localhost:5199/#/laosa](http://localhost:5199/#/laosa)。

也可以先打开 [http://localhost:5199/](http://localhost:5199/)，在工程列表点「打开老萨包装台」。工程名是「老萨包装台」，说明文字是 `laosa-packaging-demo`。示例不依赖用户素材：炭黑底、琥珀灯带、人物窗和一句锁定的「内容锁定」，加上五段剪后字幕。第一次进入会把智能音乐、动效、B-roll 的底轨写进本机偏好。

第一次编译编辑器会久一点，等到顶栏出现「包装风格 / 中文 / English / 小卡 S」再操作。

## 已知缺口

- 智能填充仍是占位。节拍对齐、动效提前约 0.75 秒、从补充素材盖 B-roll，都还没接模型。按钮会放一个带标签的占位片段，并说明尚未接入。
- 语义推荐要在设置里填写 OpenAI 兼容 API Key。这台演示机没有密钥，所以停在空态。不要把密钥写进 git。
- 包装语言会换预览字幕和章节标题。时间线字幕块仍显示源中文，因为文档本身锁的是中文口播。
- 多轨字幕（`sourceEntries`）不随包装语言切换。示例工程是单流字幕。
- 同一标签页里的浏览器导出会带上当前包装语言。无头 / 服务端 Remotion 导出还没有这条参数。
- 示例轨上的「床底氛围」等是中文标签，不随界面语言翻译。之后用「智能填充」落下的占位标签会翻译。
- 编辑器里的包装风格不改仪表盘皮肤。仪表盘默认皮肤同样是黑曼巴炭黑琥珀。
- 界面语言写在服务端内存里，不再每次同步都改写 `.env.local`。开发服务会把 `.env.local` 的修改当成环境文件整页重启；以前相同内容的写入会让页面永远刷不出来。重启进程之后，浏览器会再把当前语言同步上去。
