# 老黑剪辑台演示

产品名是 **老黑剪辑台**。默认包装是黑曼巴炭黑琥珀：背景 `#080808`，强调色 `#E18C21`，文字 `#FCFCFC`。口播内容和 Remotion 画面保持不动，切换的只有包装。

系列灵感来自抖音创作者老萨的光速剪辑工作台。那是外部来源的署名，不是本仓库的产品名。

## 怎么打开

需要 Node.js 24，并在仓库根目录执行：

```bash
npm install
cp .env.example .env.local
npm run dev
```

浏览器打开（必须是本机 `localhost` 安全上下文）：

```text
http://localhost:5199/#/laohei
```

`#/老黑剪辑台` 同样会打开，并把界面语言切到中文。首次访问会创建工程「老黑剪辑台演示」（时间线名「老黑剪辑台」）。之后从工程列表点开同名工程即可。同一版演示再访问不会覆盖你已经改过的包装偏好；只有本机还没有这份偏好时才会写入默认值。若本机还留着上一版演示工程，再次打开 `#/laohei` 会把时间线和轨道刷新一次，之后仍保留你的修改。

演示不读取用户成片。画面是 Remotion 里的炭黑纯色层、锁定标题「同一口播 / 内容锁定」，以及右上角的琥珀色包装示意（随动效段落出现，不替换标题）。字幕是夹具里的剪后口播，用来驱动章节和语义配卡。三条轨道在打开时已经铺好可见片段：智能音乐是铺满的「炭黑床乐」，动效按口播提前约 0.75 秒落「内容锁定 / 九宫格避让 / 关键词小卡 / 步骤中卡 / 完整框架 / 中英换字」，B-roll 盖住「人物避让 / 卡型对照 / 框架示意」。床乐是程序生成的轻声正弦（`public/demo/laohei-bed.wav`），不是配乐模型。

## 五块台面

1. **顶栏**：包装风格（默认黑曼巴炭黑琥珀，另有影棚琥珀、冷科技、清爽白）、中文 / English、小卡 S / 中卡 M / 全卡 F、内容锁定。
2. **检查器**：卡型与顶栏同步，九宫格决定卡片锚点和裁切焦点。
3. **语义配卡**：没有 OpenAI 兼容 API Key 时仍显示空态，并提供「打开 OpenAI 设置」。同一空态里有「演示模式」：不联网，按播放头所在字幕给出确定性的 S/M/F，结果标成「演示」，可以点「采用」。配好密钥后，仍可按当前字幕请求模型推荐。
4. **章节**：按剪后字幕的停顿分章。预览上方有章节条，检查器里有章节列表，点击会跳到该章。
5. **时间线轨道**：智能音乐、动效、B-roll。演示工程打开时三轨已有标注片段。拖入素材会自动落到空档。「智能填充」按钮本身仍只放下 `laosa:*` 占位片段，没有接模型。

中英切换只换字幕和界面文字，不改声音和时间。本演示没有人声音轨；能听到的只是那条轻声床乐。

## 缺口

- 语义配卡在没有密钥时仍是空态。仓库不存放 API Key。空态里的「演示模式」是离线、确定性的，结果标明「演示」，不是模型推荐。真正的「按语义推荐」仍要 OpenAI 兼容密钥。
- 「智能填充」按钮仍只自动落一个 `laosa:*` 占位片段（`TODO(laosa)`），没有接配乐、图解或 B-roll 模型。`#/laohei` 上看起来铺满的轨道是夹具里的标注片段和一条生成的轻声正弦，不是模型填充。
- 演示画面是纯色舞台、锁定标题和琥珀色包装示意，不是口播实拍；没有用户媒体，也没有真人声。
- 代码与路由标识仍用 `laosa`（例如 `src/laosa/`、`/api/laosa/semantic-card`、占位标签 `laosa:music`）。它们不是界面上的产品名。
