# 老黑剪辑台演示

产品名是 **老黑剪辑台**。默认包装是黑曼巴炭黑琥珀：背景 `#080808`，强调色 `#E18C21`，文字 `#FCFCFC`。口播内容和 Remotion 画面保持不动，切换的只有包装。

系列灵感来自抖音创作者老萨的光速剪辑工作台。那是外部来源的署名，不是本仓库的产品名。

## 怎么打开

需要 Node.js 24，并在仓库根目录执行：

```bash
export NVM_DIR="$HOME/.nvm"; . "$NVM_DIR/nvm.sh"; nvm use 24
npm install
cp .env.example .env.local   # 可选；密钥更推荐在应用内「设置」里填
npm run dev
```

浏览器打开（必须是本机 `localhost` 安全上下文）：

```text
http://localhost:5199/#/laohei
```

`#/老黑剪辑台` 同样会打开，并把界面语言切到中文。首次访问会创建工程「老黑剪辑台演示」（时间线名「老黑剪辑台」）。

手机预览可用 Cloudflare Tunnel / ngrok 挂 5199；本仓库 Vite 已设 `allowedHosts: true`。

## 配置 OpenAI 兼容 API Key（语义真填）

1. 打开检查器「语义配卡」→ **打开 OpenAI 设置**（路由 `llm/openai`）。
2. 填写 **API Key**（`LLM_OPENAI_API_KEY` 或兼容的 `OPENAI_API_KEY`），可选 Base URL / 模型。
3. 密钥只写在本机设置存储（与 OpenChatCut 其它密钥相同），**不会写入仓库**。
4. 也可在 `.env.local` 里设 `LLM_OPENAI_API_KEY=...`（同样勿提交）。

配好后点 **按语义推荐** → **采用**：会改卡型，并在动效轨落一条带 S/M/F 的标注片段。

未配置密钥时，同一空态里的 **演示模式** 仍可用：离线、按播放头字幕给确定性建议，结果标「演示」。密钥就绪后演示模式仍作为兜底保留。

## 替换口播成片素材

检查器顶部有 **口播成片**：

- 空态时可 **导入口播素材**（本机视频/图片，blob URL，仅本浏览器）。
- 或点 **使用演示口播占位**，加载 `public/demo/laohei-vo.mp4`。
- 要换默认演示文件：直接覆盖 `public/demo/laohei-vo.mp4`（自行准备、注意版权），再点「使用演示口播占位」。
- **清除口播** 回到空位。包装卡片叠在 VO 预览之上，不重生成 Remotion 时间线内容。

床乐仍是 `public/demo/laohei-bed.wav`（程序生成轻声正弦）。

## 五块台面（已接通）

1. **顶栏**：包装风格 / 中英 / S·M·F — 会真实驱动壳层色板、卡片文案语言、预览卡片尺寸与锚点（`data-laosa-lang` / `data-laosa-style` / `data-laosa-card`）。
2. **检查器**：卡型、九宫格、语义配卡、章节；选中轨片段后可改标签、改动效卡型、跳转、删除。
3. **语义配卡**：有密钥走 `/api/laosa/semantic-card`；无密钥用演示模式。采用后联动动效轨。
4. **章节**：按剪后字幕停顿分章；预览条与检查器列表可跳转。
5. **三轨**：智能音乐 / 动效 / B-roll。点击片段可选中；拖入素材自动落点；**智能填充**按当前字幕落标注（无密钥标「演示·」；有语义结果时动效带卡型）。

## 仍为演示 / 兜底的部分

- 无 API Key 时语义与智能填充走离线演示启发式，不是上游模型。
- 智能填充不会调用配乐 / B-roll 生成模型；只落标注轨片段（可拖真实文件上去）。
- Remotion 时间线里的炭黑舞台与锁定标题仍是夹具；口播预览是包装层 VO 槽，不替代导出成片管线。
- 代码与路由标识仍用 `laosa`（例如 `src/laosa/`、`/api/laosa/semantic-card`）。它们不是界面上的产品名。
